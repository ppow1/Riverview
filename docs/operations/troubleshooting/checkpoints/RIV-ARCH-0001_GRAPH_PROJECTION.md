# RIV-ARCH-0001 — Generated architecture projection semantics

Use this checkpoint when a graph generator completes but its human-readable
projection is not trustworthy. Compare generated JSON, Mermaid, and DOT from
the same canonical graph. Reject unresolved template markers, empty labels,
unknown node references, duplicate declarations, and nondeterministic output.

The repair is in the generator, never in a generated projection. Verification
must regenerate the artifacts, validate semantic node/edge correspondence, and
inspect representative human-readable declarations.
