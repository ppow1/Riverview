# RV-014.1 registry implementation evidence

Riverview now has a reference-only resident registry and role-context boundary.
It preserves stable identity, source reference, role, provenance, classification,
certainty, and continuity reference. Duplicate identical records are idempotent;
conflicting provenance is rejected. Unknown facts remain `unknown`.

No real resident records were imported because the authoritative source set is
still empty. The fixture tests prove the mechanism without inventing identity.
