# RV-018.3 security and Undercurrent review

Executable checks cover classification denial, protected broker denial,
credential lifecycle, synthetic encrypted restore, explicit declassification,
authenticated voice, browser/operator authority boundaries, and reference-only
artifact handling. The review contains no protected payload or secret.

Findings and owners:

- Protected reads/declassification: `riverview.security`, owner Riverview
  security boundary; unauthorized requests fail closed.
- Credentials: `riverview.security.credentials`, owner credential lifecycle;
  secret material is absent from ordinary evidence.
- Operator/provider authority: `riverview.operator` and provider-neutral
  envelope, owner operator/reasoning boundary; provider identity adds no
  authority.
- Backup/restore: `riverview.late_stage.recovery`, owner recovery boundary;
  classification and credential references are preserved.
- LAN spatial surface: `riverview.operator.lan_spatial`, owner operator
  surface; only read-only spatial routes are exposed and TLS is required.

## Executed review

The bounded review was executed against the Riverview security and operator
contracts with synthetic references only. The applicable security, broker,
credential, recovery, declassification, voice, browser, and artifact tests
passed. The review also verified that the ordinary operator/provider path
does not receive Undercurrent authority from provider identity, that bearer
material is absent from browser handoff evidence, and that reference-only
artifacts do not expose payload bytes.

The negative cases remain fail-closed: unauthorized protected reads and
declassification are denied; empty or invalid credentials are denied;
unauthenticated voice requests are denied; and an artifact reference carries
metadata rather than protected content. Backup/restore evidence preserves
classification and credential references.

Finding owners are the security boundary, credential lifecycle, operator /
reasoning boundary, recovery boundary, and LAN operator surface respectively;
there are no unowned critical findings in this bounded review.
