# RV-016.5 LAN deployment preparation

The read-only spatial prototype is available from the existing loopback
operator service at `/spatial`. A separate bounded TLS listener can expose
only `/spatial` and `/health` on the private LAN host `192.168.1.88:18443`.
It has no chat, database, shell, provider, or control endpoints and uses a
short-lived local certificate under the runtime operator TLS directory.

The listener is implementation/preparation evidence, not Quest acceptance.
WebXR still requires Pat's Quest browser to trust the local certificate (or a
trusted private-LAN certificate) and to establish an actual `immersive-vr`
session. No public exposure is authorized.
