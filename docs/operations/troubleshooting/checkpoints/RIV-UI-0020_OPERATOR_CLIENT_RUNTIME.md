# RIV-UI-0020 — Operator client runtime boundary

Use this checkpoint when the Riverview Operator page renders but application
controls are inert while native browser controls still work. Extract the live
inline script and run a JavaScript syntax check first. If it fails, repair the
generated HTML/JavaScript source, restart the service, and repeat the documented
live authentication, resident, snapshot, and submit probes. Do not treat API
health alone as browser acceptance.
