# RV-018.6 final acceptance packet

## Current system

Riverview now provides bounded Grace/provider execution, ChatGPT/Comms and
local-provider reasoning, browser operator interaction with real local
microphone/STT, reference-only artifact intake, project intake/Codex delivery,
knowledge extraction/memory, resident registry and role isolation,
classification/credentials/Undercurrent boundaries, isolated recovery,
service topology, observability, parity adapters, migration verification,
shadow drills, Cookbook coverage, fresh-context recovery, and extension
contracts.

## Explicit limitations

- RV-016.5 has a browser/WebXR-capable prototype and private-LAN TLS listener,
  but no Meta Quest session, real headset input, frame/comfort, or user-visible
  latency acceptance.
- RV-017.6 has no approved authority transfer or legacy retirement. Estate
  physical infrastructure remains external/reference scope.
- RV-018.3 is prepared but dependency-held by RV-017.6.

The final acceptance cannot be promoted while these canonical limitations remain
unaccepted. No limitation is hidden or represented as completed.

## Resident conversation parity

See `RV-018.6_RESIDENT_CONVERSATION_PARITY_AUDIT.md` for the Estate/Riverview
capability map. Riverview now has a shared resident/session gateway,
authoritative resident selection in the browser operator, Grace
conversational addressability with explicit seed-promotion gating, and a
bounded room/session API. Identity, provenance, classification, correlation,
and role-authority separation are machine-tested.

Final acceptance remains pending because fresh human resident switching and a
full human room workflow have not yet been Steward-accepted; the Estate room
implementation is real and Riverview's equivalent is currently partial.

## Character development and runtime parity

See `RV-018.6_CHARACTER_DEVELOPMENT_AND_RESIDENT_PARITY.md`. Riverview now
separates the Character Designer workflow from runtime conversation: accepted,
versioned resident definitions are published through review, while sessions
consume only accepted versions and governed continuity references. Proposals,
rejections, unresolved material, session history, and accepted continuity are
distinct. The bounded room path now performs ordered provider-generated resident
turns while preserving speaker identity and authority boundaries. Human resident
switching and room exercise remain explicitly unclaimed until observed.
